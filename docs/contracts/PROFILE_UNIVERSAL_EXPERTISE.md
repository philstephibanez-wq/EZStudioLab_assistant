# Contrat PROFILE universel — v1.6a(104)

## Décision
Toute chanson, toute combinaison d'instruments, toutes les **valeurs finales** PROFILE effectivement exposées dans le contrat public LAB doivent être expertisées individuellement. Aucune liste de chansons, d'artistes ou d'instruments autorisés. Les valeurs non émises ne deviennent pas automatiquement des assertions.

## Frontière de sécurité
Le vérificateur externe ne reçoit ni noms de moteurs, ni scores scientifiques internes, ni réglages de presets : séparation LAB (#17) / Assistant (#11 et #12). La couverture exhaustive des valeurs musicales requiert un schéma de sortie finale LAB évolutif, avec identifiants stables, types, valeurs et absence explicite. Un champ interne non éligible ne doit pas être divulgué pour obtenir l'exhaustivité.

## Critères du flux cible
1. Identification multi-candidats de l'enregistrement : interprète, titre, durée, version, édition et provenance ; abstention en cas d'ambiguïté.
2. Inventaire dynamique : égalité des nombres d'assertions finales éligibles exposées et expertisées ; chacune conserve valeur, type, identifiant et état.
3. Preuve indépendante par item : identité du bon enregistrement, liens sûrs, concordance sémantique, abstention si preuve absente ; jamais FAUX sur absence de crédits.
4. Publication intégrale des comparaisons et motifs d'abstention, incluant les changements de liste d'instruments et les versions multiples d'une œuvre.
5. Réutilisation des validations humaines persistées ; amélioration des presets proposée côté LAB uniquement sur corpus diversifié avec benchmark avant/après, aucune mutation directe du preset actif.

## Validation / limite
Cette livraison verrouille le contrat et ajoute le test de cardinalité des instruments arbitraires ; elle **ne prétend pas** achever l'inventaire de toutes les dimensions ni l'identification universelle. Tests ajoutés mais non exécutés sur XPS. Aucun moteur scientifique changé.

## Handoff
Suite : définir avec LAB l'export canonique dynamique de toutes les sorties musicales finales, sans télémétrie moteur ; remplacer ensuite le projecteur à liste fixe dans Assistant, tester plusieurs chansons hétérogènes et produire une preuve réelle dans le dépôt privé.
