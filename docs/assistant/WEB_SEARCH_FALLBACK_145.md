# Discovery search fallback v1.6a(145)

Suite au diagnostic MAIN #181 et #182 : DuckDuckGo HTML et Bing répondaient sans liens sortants sur 10 requêtes. Correctif : recherche générique multi-moteur avec DuckDuckGo HTML, Bing HTML, DuckDuckGo Lite, Mojeek et Google, dans cet ordre. Parsing des redirections DDG (`uddg`) et Google (`/url?q`) ; domaines externes HTTPS publics uniquement ; aucune dépendance à une liste figée de sites musicaux. Les pages peuvent toujours bloquer les robots ; `discovery_failed` reste un échec explicite et **n'est pas un verdict musical**. Un résultat Web ne suffit pas à `completed`. Les checkpoints discovery-v1 existants sont immuables : pour tester sans conflit, exécuter une recherche en lecture seule via `analyze()` ; ne pas réécrire `--record-discovery` sur #181/#182 tant que versionnement des tentatives n'est pas ajouté. Contrat réseau SSRF : vérifier egress protections du réseau hôte ; aucun contournement de captcha.
