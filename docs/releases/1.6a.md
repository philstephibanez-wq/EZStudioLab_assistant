# EZStudioLab Assistant v1.6a — PROFILE, vérification indépendante

Date : 22 octobre 2026

## Objet
L'Assistant ne reçoit plus les sorties des 12 moteurs scientifiques pour produire des commentaires. Son entrée métier est limitée à l'identité du titre/interprète/enregistrement et aux valeurs musicales finales de LAB. Il retourne, pour chaque valeur finale disponible, un verdict **BON / FAUX / NON TROUVÉ**, avec les liens des sources probantes, ou une abstention.

## Inclus
- Nouveau moteur `app/profile_final_verifier.py` : tempo, mesure, tonalité, genre, instrumentation (un instrument par assertion), voix principale, voix d'accompagnement, harmonies vocales, chœurs.
- Le worker PROFILE utilise `comparison.final_verification.assertions` et ne requiert plus de consultation Qwen des 12 moteurs.
- Descriptions techniques et paramètres des moteurs hors contexte du vérificateur ; conservation des diagnostics LAB et des rapports privés.
- Références externes : recherche publique existante, correspondance identité de l'enregistrement et contrôle d'URL HTTPS. Une preuve explicite de crédits par enregistrement ou de genre propre à l'enregistrement peut permettre BON. Les sources sans preuve n'autorisent jamais BON/FAUX.
- Confidences `null` en l'absence de calibration. Aucun score/pourcentage inventé. FAUX exige une preuve contradictoire positive ; les sources actuellement exploitées ne permettent pas encore de conclure FAUX pour tous les types de valeurs.
- Interface LAB : une ligne par assertion, lien HTTPS cliquable si probant, rendu BON / FAUX / NON TROUVÉ, anciennes révisions signalées séparément.
- Tests unitaires `tests/test_profile_final_verifier_v16a.py` : cloisonnement, crédibilité des références, abstention, cardinalité des instruments, sans fabrication de verdict.

## Limites explicites
- La majorité des assertions (tempo, mesure, tonalité, chœurs) peuvent être NON TROUVÉ faute de références externes fiables dans les sources actuellement intégrées. Ce n'est pas un échec du moteur scientifique LAB.
- Pas d'écoute audio ni de preuve sonore autonome ; Qwen n'est pas une source indépendante.
- Aucun pourcentage fiable sans base de calibration. Aucune promotion de preset scientifique.
- La publication GitHub des commits n'installe **pas** les fichiers sur MAIN ou XPS. Un test réel de bout en bout reste obligatoire avant de marquer la release comme opérationnelle.

## Livraison / validation attendue
- MAIN `H:\EZStudio_lab` : `git pull --ff-only origin main`, `php bin/console lint:twig templates/workbench/profile.html.twig`.
- XPS `C:\EZStudioLab_assistant` : `git pull --ff-only origin main`, `python -m unittest discover -s tests -p test_profile_final_verifier_v16a.py -v`, compilation `python -m py_compile app\profile_final_verifier.py runtime\profile_ai_requests_worker.py`.
- Après prévol, redémarrage **ciblé** du worker PROFILE sous Guardian et un seul run d'évaluation, aucune régénération scientifique.
- Critère end-to-end : chaque valeur finale a exactement une ligne verdict, avec source si BON/FAUX et sans source fabriquée si NON TROUVÉ.
