# 1.6a(105) — Raccordement final_assertions

Le worker lit l'API LAB authentifiée pour chaque run, et la même liste alimente le vérificateur et la recherche documentaire. Incohérence de schéma ou cardinalité : arrêt explicite, sans fallback silencieux.

Validation : tests ajoutés, non exécutés sur XPS ; test réel à effectuer après déploiement conjoint LAB.

Aucun preset, moteur scientifique ou rapport historique modifié. L'exhaustivité reste limitée à l'inventaire effectivement émis par LAB.
