# v1.6a(118) — Socle SearXNG expérimental

Ajoute un adaptateur expérimental SearXNG JSON sans clé et strictement loopback, un contrat d'architecture open source sans API payante et des tests offline de normalisation et de refus d'accès externe. Aucun déploiement sur XPS, aucun processus arrêté, pas de modification des moteurs musicaux ni du worker. Intégration de Local Deep Researcher différée à une tranche dédiée. Tests à exécuter sur XPS, pas de résultat annoncé anticipativement.
