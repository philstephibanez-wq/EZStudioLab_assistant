# v1.6a(114) — Correction du chemin UNC MAIN

Un partage UNC comme `\\EZSTUDIO-MAIN\EZModels` est un ancrage Windows : `Path.name` vaut une chaîne vide, contrairement à un sous-répertoire. Remplace la mauvaise validation par une comparaison stricte du chemin UNC canonique avec `PureWindowsPath`. Tests Windows racine et refus de partages incorrects. Aucune modification d'inférence, modèle ou LAB.
