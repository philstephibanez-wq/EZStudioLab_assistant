## Contrat
- Calcul OCR sur XPS (Tesseract installé sous \`C:\Program Files\Tesseract-OCR\tesseract.exe\`).
- Modèles \`eng.traineddata\` et \`fra.traineddata\` conservés exclusivement sur MAIN, dans le dossier physique qui correspond à \`\\EZSTUDIO-MAIN\EZModels\tesseract\tessdata_best\`.
- \`EZS_TESSERACT_EXE\` et \`EZS_TESSDATA_DIR\` peuvent remplacer respectivement l'exécutable et le chemin de modèles. Il n'y a **aucun téléchargement ni copie implicite** des modèles.
- Avant lecture : existence de l'exécutable et des deux langues, puis vérification réelle par \`--list-langs --tessdata-dir\`. Échec fermé si inaccessible.
- L'OCR reste **désactivé par défaut** et ne fonctionne que si \`EZS_PROFILE_BOOKLET_OCR=1\` est défini dans l'environnement du worker supervisé, puis le worker redémarré hors job.
- Toujours \`evidence_eligible=False\` pour les candidats OCR : aucun BON/FAUX automatique à partir d'un scan.
- Pas de déploiement automatique, pas de mutation scientifique.

## Préparation des modèles sur MAIN
Vérifier d'abord le répertoire physique mappé sur le partage \`EZModels\`. L'exemple ci-dessous suppose qu'il correspond à \`H:\EZModels\` ; ajuster **uniquement** si le partage réel pointe ailleurs.

\`\`\`powershell
# MAIN : Powershell
Get-SmbShare -Name EZModels | Select-Object Name,Path
# Remplacer H:\EZModels par le Path affiché si différent.
$target = 'H:\EZModels\tesseract\tessdata_best'
New-Item -ItemType Directory -Force -Path $target | Out-Null
$base = 'https://raw.githubusercontent.com/tesseract-ocr/tessdata_best/main'
foreach ($lang in @('eng','fra')) {
    Invoke-WebRequest "$base/$lang.traineddata" -OutFile (Join-Path $target "$lang.traineddata")
}
Get-ChildItem $target -Filter '*.traineddata' | Select-Object Name,Length
