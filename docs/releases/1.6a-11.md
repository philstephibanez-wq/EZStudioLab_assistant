# Assistant v1.6a(11) — crédits des éditions, piste exacte

Le connecteur `app/profile_release_track_credits.py` inspecte jusqu'à deux éditions MusicBrainz, avec l'option API `recordings+recording-level-rels+artist-rels`. Il conserve uniquement les relations de l'objet `media[].tracks[].recording` dont l'identifiant correspond exactement à l'enregistrement sélectionné ; les crédits attachés à la release entière sont interdits. Le composant de vérification existant peut ainsi exploiter les crédits positifs de musiciens et voix d'une édition dans la comparaison PROFILE. Limites réseau communes conservées.

**Attention :** davantage de requêtes ne garantit pas davantage de crédits : les relations MusicBrainz peuvent être vides. Aucune donnée BPM, mesure ou tonalité n'est fournie par ce connecteur. OCR provisoire inchangé ; moteurs scientifiques intacts ; aucun déploiement automatique.

Tests : `tests/test_profile_release_track_v16a11.py` (piste exacte, UUID invalide, album-wide interdit).
